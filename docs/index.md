# Mauri Gourmet

Cocina casera y amateur. Cada receta está clasificada de tres formas:

| Clasificación | Valores |
|---|---|
| **Origen** | País o región (Argentina, Italia, Medio Oriente…) |
| **Aporte nutricional** | Carbohidrato · Proteína · Lípido · Fibra |
| **Comida del día** | Desayuno · Merienda · Almuerzo · Cena |

## Cómo explorar

- [Todas las recetas](recetas/index.md)
- [Explorar por etiquetas](tags.md): agrupadas por origen, nutriente y comida.
- Usá el buscador (arriba) para encontrar por nombre o ingrediente.
